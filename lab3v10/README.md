## Відповіді на контрольні запитання

1. Що таке життєвий цикл об’єкта в .NET?  
Життєвий цикл об’єкта охоплює його створення (виділення пам’яті в купі та виклик конструктора), використання через посилання, збирання сміття (GC) та фіналізацію (виклик деструктора) перед остаточним видаленням[cite: 7].

2. Яка різниця між керованими та некерованими ресурсами?  
Керовані ресурси — це пам’ять і об’єкти, якими повністю керує середовище .NET і збирач сміття. Некеровані ресурси — це файлові дескриптори, з’єднання з БД, мережеві потоки або системні буфери, які вимагають ручного звільнення[cite: 7].

3. Для чого призначений інтерфейс IDisposable?  
Інтерфейс `IDisposable` надає стандартний механізм для явного та детермінованого звільнення некерованих ресурсів за допомогою методу `Dispose()`[cite: 7].

4. Як оператор using допомагає в керуванні ресурсами?  
Оператор `using` гарантує автоматичний виклик методу `Dispose()` для об'єкта одразу після виходу з блоку коду, навіть якщо під час виконання виникне виняток (exception)[cite: 7].

5. Навіщо в патерні Dispose використовується метод GC.SuppressFinalize()?  
Метод `GC.SuppressFinalize(this)` повідомляє збирачу сміття, що ресурс вже було звільнено вручну через `Dispose()`, тому немає потреби викликати деструктор (фіналізатор) для цього об'єкта, що підвищує продуктивність[cite: 7].

6. Чому в деструкторі викликається Dispose(false), а в методі Dispose() - Dispose(true)?  
У методі `Dispose()` передається `true`, оскільки ми можемо безпечно звільняти як керовані, так і некеровані ресурси. У деструкторі передається `false`, оскільки фіналізатор викликається збирачем сміття в непередбачуваному порядку, і звертатися до інших керованих об'єктів у цей момент небезпечно.

## Структура класу `ImageBuffer`

### 1. Приватні поля
* `_disposed` (`bool`) — прапорець для запобігання повторного виклику звільнення ресурсів.
* `_width` (`int`) — ширина буфера зображення[cite: 7].
* `_height` (`int`) — висота буфера зображення[cite: 7].
* `_isAllocated` (`bool`) — стан виділення буфера у пам'яті[cite: 7].

### 2. Властивості
* `Width` — повертає ширину буфера зображення.
* `Height` — повертає висоту буфера зображення.

### 3. Конструктори та управління ресурсами
* **Конструктор:** імітує виділення пам'яті для буфера зображення та встановлює `_isAllocated = true`[cite: 7].
* `Dispose()` / `Dispose(bool disposing)` — реалізують патерн звільнення буфера (`_isAllocated = false`)[cite: 7].
* **Деструктор:** викликає `Dispose(false)` для фіналізації[cite: 7].

### 4. Методи
* `DrawPixel(int x, int y)` — імітує малювання пікселя у буфері, якщо він виділений[cite: 7].

## Демонстрація роботи

2. Явний виклик методу `Dispose()`.
3. Створення об'єкта без виклику `Dispose()` з демонстрацією роботи деструктора через `GC.Collect()`.
