# Лабораторна робота №11

## Тема
LINQ: SelectMany, пагінація й custom extensions.

## Мета
Навчитися використовувати оператор SelectMany для роботи з вкладеними колекціями, реалізовувати пагінацію даних за допомогою LINQ, а також створювати власні методи розширення для ключових доменних сутностей[cite: 1].

## Варіант 10
* **Сутності:** Product (Id, Name, List), Feature (Id, Name, List), Option (Id, Value)[cite: 1].
* **Запити:**
  1. `SelectMany`: Отримати всі опції всіх характеристик всіх продуктів в одному списку[cite: 1].
  2. **Пагінація:** Вивести всі продукти по 3 продукти на сторінку[cite: 1].
  3. **Custom Extension:** Метод розширення `HasFeature(string featureName)` для `Product`, що перевіряє наявність характеристики[cite: 1].
