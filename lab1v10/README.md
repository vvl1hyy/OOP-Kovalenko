## Опис проєкту

Консольний застосунок на C# (.NET SDK), що демонструє роботу з класом `Computer`, реалізацію приватних полів, публічних властивостей з інкапсуляцією, базового конструктора та методу обчислення продуктивності.

---

## Структура класу `Computer`

### 1. Приватні поля
* `_cpu` (`string`) — назва процесора.
* `_ramGB` (`int`) — обсяг оперативної пам'яті в гігабайтах.
* `_storageGB` (`int`) — обсяг накопичувача в гігабайтах.

### 2. Властивості
* `CPU` — публічний доступ до назви процесора.
* `RAMGB` — публічний доступ до обсягу оперативної пам'яті.
* `StorageGB` — публічний доступ до обсягу накопичувача.

### 3. Конструктори
* **Параметризований:** `Computer(string cpu, int ramGB, int storageGB)` — ініціалізує об'єкт переданими значеннями.

### 4. Методи
* `RunBenchmark()` — виводить інформацію про запуск тесту та обчислює бали продуктивності.
* `GetInfo()` — повертає рядок із характеристиками комп'ютера.
