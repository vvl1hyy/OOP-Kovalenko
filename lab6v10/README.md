## Відповіді на контрольні запитання

### 1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.
Наслідування — це механізм ООП, що дозволяє створювати нові класи (похідні) на основі існуючих (базових), переймаючи їхні поля, властивості та методи. Це створює відношення "є-різновидом". Наприклад: базовий клас `Building` (Будівля), від якого наслідуються конкретні типи `House` (Будинок) та `Skyscraper` (Хмарочос).

### 2. Для чого використовується ключове слово base? Наведіть приклади його застосування.
Ключове слово `base` використовується для доступу до членів базового класу з похідного. Найчастіший випадок — виклик конструктора базового класу (наприклад, `public House(string a, int y) : base(a, y)`), щоб не дублювати код ініціалізації полів. Також `base` дозволяє викликати метод базового класу всередині перевизначеного методу (`base.GetInfo()`).

### 3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?
Модифікатор `virtual` у базовому класі дозволяє похідним класам змінювати реалізацію методу. Модифікатор `override` у похідному класі безпосередньо замінює цей віртуальний метод. Разом вони забезпечують динамічний поліморфізм: навіть якщо ми звертаємося до об'єкта через посилання базового типу, виконається перевизначена версія методу того класу, об'єкт якого було реально створено.

### 4. Коли варто використовувати модифікатор new для приховування члена базового класу, і які наслідки це має?
Модифікатор `new` використовується, коли потрібно створити метод з таким самим ім'ям, як у базовому класі, але базовий метод не є `virtual`, або коли ми свідомо не хочемо поліморфної поведінки. Наслідок: метод приховується, а не перевизначається. Те, яка версія методу виконається, буде залежати виключно від типу посилання, через яке йде виклик, а не від фактичного типу об'єкта.

## Структура ієрархії класів

### 1. Базовий клас `Building`
- Поля та властивості: `Address` (адреса), `YearBuilt` (рік побудови).
- Методи: конструктор для ініціалізації, віртуальний метод `virtual void GetInfo()`, звичайний метод `GetBuildingType()`.

### 2. Похідний клас `House`
- Поля та властивості: `NumFloors` (кількість поверхів).
- Методи: конструктор із викликом `base`, перевизначений метод `override void GetInfo()`, унікальний метод `OpenDoor()`, та прихований метод `new string GetBuildingType()`.

### 3. Похідний клас `Skyscraper`
- Поля та властивості: `NumElevators` (кількість ліфтів).
- Методи: конструктор із викликом `base`, перевизначений метод `override void GetInfo()`, унікальний метод `GoToRoof()`.
