# Самостійна робота №20: Реалізація exponential backoff з jitter

**Виконав:** Коваленко Владислав, група ІПЗ 3-2

## Опис
У проєкті `IndependentWork14` реалізовано узагальнений клас `RetryPolicy` з методом `Execute<T>`, експоненційною затримкою (`Math.Pow(2, retryAttempt)`), випадковим відхиленням (`jitterFactor`) та фільтрацією помилок через `shouldRetry`[cite: 23].

## Висновок щодо меж застосування Retry з exponential backoff
Патерн `Retry` з експоненційною затримкою та `jitter` ефективний лише для тимчасових (transient) збоїв — короткочасних проблем мережі, перевантаження сервісу або таймаутів, коли є шанс на відновлення за кілька спроб[cite: 23]. Його не слід застосовувати до постійних помилок (помилки валідації, 401/403/404, некоректні дані), критичних бізнес-винятків або неідемпотентних операцій без захисту від дублювання (наприклад, повторне списання коштів), а також у сценаріях із жорсткими обмеженнями часу відповіді користувачу[cite: 22, 23].
