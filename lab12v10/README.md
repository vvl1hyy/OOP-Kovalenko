# Лабораторна робота №12

## Тема
Обробка IO/мережевих помилок та патерн Retry[cite: 2].

## Мета
Навчитися обробляти типові помилки вводу/виводу та мережеві помилки за допомогою блоків try-catch-finally, а також реалізувати патерн Retry для підвищення відмовостійкості застосунків[cite: 2].

## Варіант 10
* **Сценарій:** Відправка електронного листа[cite: 2].
* **FileProcessor:** Метод `GetEmailTemplate(string path)` (імітація `IOException` перші 3 рази, потім успіх)[cite: 2].
* **NetworkClient:** Метод `SendEmail(string recipient, string subject, string body)` (імітація `HttpRequestException` перші 2 рази, потім успіх)[cite: 2].
* **shouldRetry:** Повторювати для `IOException` та `HttpRequestException`[cite: 2].

## Висновок
Експоненційна затримка усуває зайве навантаження на систему або мережу, збільшуючи час очікування між кожною наступною невдалою спробою за допомогою формули множення початкової затримки на степені двійки.
