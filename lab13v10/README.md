# Лабораторна робота №13

## Тема
Власні винятки та патерн Result[cite: 3].

## Мета
Навчитися створювати власні типи винятків для специфічних помилок, а також реалізовувати патерн Result для більш контрольованої обробки помилок без використання винятків у “нормальних” сценаріях невдачі[cite: 3].

## Варіант 10
* **Сценарій:** Управління інвентарем[cite: 3].
* **Власний виняток:** `ProductOutOfStockException (int ProductId, int RequestedQuantity)`[cite: 3].
* **Service:** `InventoryService`[cite: 3].
  1. Метод `DecreaseStock(int productId, int quantity)`: Викидає `ProductOutOfStockException`, якщо товару недостатньо[cite: 3].
  2. Метод `Result<bool> AddStock(int productId, int quantity)`: Повертає `Result.Success` або `Result.Failure` (якщо кількість <= 0)[cite: 3].

## Висновок
Використання власних винятків є доцільним для критичних і непередбачуваних помилок програми, які переривають нормальний хід виконання. Патерн `Result<T>` ідеально підходить для передбачуваних бізнес-помилок та валідації вхідних даних, оскільки дозволяє уникнути витрат ресурсів на генерацію винятків і робить код більш читабельним.
