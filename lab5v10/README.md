## Відповіді на контрольні запитання

### 1. Що таке поліморфізм і як він реалізується в C# за допомогою virtual та override?
Поліморфізм — це здатність об’єктів різних класів реагувати на однаковий виклик методу по-різному, залежно від їхнього фактичного типу. У C# він реалізується за допомогою модифікатора `virtual` у базовому класі та `override` у похідних класах.

### 2. Поясніть поняття динамічного зв’язування. Чим воно відрізняється від статичного?
Динамічне зв’язування (Late Binding) — це визначення того, який саме метод буде викликано, безпосередньо під час виконання програми. На відміну від статичного зв’язування (яке визначається на етапі компіляції), воно дозволяє повноцінно реалізувати поліморфну поведінку.

### 3. Наведіть приклад, як поліморфізм дозволяє писати більш гнучкий та розширюваний код.
Поліморфізм дозволяє створювати методи або цикли обробки, які працюють із базовим типом (наприклад, `Game`). Завдяки цьому при додаванні нових класів ігор не потрібно змінювати існуючий код обробника чи колекції.

### 4. Які переваги дає використання колекцій базових типів для роботи з поліморфними об’єктами?
Колекції базових типів (наприклад, `List<Game>`) дають змогу зберігати різнорідні похідні об’єкти в єдиному списку та викликати віртуальні методи в єдиному циклі, забезпечуючи зручну обробку та агрегацію даних.

## Структура ієрархії класів

### 1. Базовий клас `Game`
* Поля та властивості: `Title` — назва гри.
* Методи: конструктор для ініціалізації назви, віртуальний метод `virtual void Play()`.

### 2. Похідний клас `BoardGame`
* Поля та властивості: `MinPlayers`, `MaxPlayers` — мінімальна та максимальна кількість гравців.
* Методи: конструктор із викликом `base`, перевизначений метод `override void Play()`.

### 3. Похідний клас `VideoGame`
* Поля та властивості: `Platform` — ігрова платформа.
* Методи: конструктор із викликом `base`, перевизначений метод `override void Play()`.

### 4. Похідний клас `CardGame`
* Поля та властивості: `NumDecks` — кількість колод карт.
* Методи: конструктор із викликом `base`, перевизначений метод `override void Play()`.
