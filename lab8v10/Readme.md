## Відповіді на контрольні запитання

### 1. Що таке делегат і для чого він використовується?
Делегат — це тип даних у C#, який зберігає посилання на метод (або кілька методів) із певною сигнатурою (набором параметрів та типом повернення). Він використовується для того, щоб передавати методи як параметри в інші методи (так звані callback-функції), а також для реалізації подій (events)[cite: 37].

### 2. У чому полягає різниця між Func та Action?
- `Action` — це узагальнений делегат, який представляє метод, що виконує дію, але **не повертає значення** (тип повернення `void`)[cite: 37].
- `Func` — це узагальнений делегат, який представляє метод, що **обов'язково повертає значення**[cite: 37]. Останній тип у кутових дужках завжди вказує на тип значення, яке поверне цей метод.

### 3. Як лямбда-вирази спрощують роботу з делегатами?
Лямбда-вирази дозволяють писати компактні "анонімні методи" прямо в місці виклику, без необхідності створювати окремий повноцінний метод у класі[cite: 37]. Це робить код набагато коротшим і читабельним (наприклад, `p => p.Price > 100`).

### 4. Які переваги дають узагальнені методи при роботі з колекціями?
Узагальнені методи (generics) дозволяють написати логіку обробки (наприклад, пошук) лише один раз для універсального типу `T`[cite: 37]. Після цього метод може безпечно і типізовано працювати з будь-якими колекціями (`List<int>`, `List<string>`, `List<Product>`), не потребуючи дублювання коду[cite: 37].

## Структура класів

### 1. Узагальнений клас `CollectionHelper<T>`
- Методи: статичний метод `FirstOrDefault(IEnumerable<T> collection, Predicate<T> predicate)`, який перебирає колекцію та повертає перший елемент, що відповідає умові, або `default(T)`[cite: 37].

### 2. Допоміжний клас `Product`
- Поля та властивості: `Name` (назва товару), `Price` (ціна).
- Методи: конструктор для ініціалізації полів, перевизначений метод `override string ToString()` для зручного виводу інформації про товар у консоль.

### 3. Головний клас `Program`
- Методи: `Main()`, де відбувається ініціалізація колекцій (`List<string>` та `List<Product>`) і демонстрація роботи методу `FirstOrDefault` за допомогою лямбда-виразів.
