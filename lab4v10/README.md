## Відповіді на контрольні запитання

1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.  
Наслідування — це механізм ООП, який дозволяє створювати новий клас на основі вже існуючого, успадковуючи його поля та методи[cite: 4]. Приклад: базовий клас «Транспортний засіб» і похідні «Автомобіль» та «Мотоцикл».

2. Для чого використовується ключове слово base? Наведіть приклади його застосування.  
Ключове слово `base` використовується для доступу до членів базового класу з похідного класу, найчастіше для виклику конструктора базового класу через `base(...)`[cite: 4] або перевизначеного методу.

3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?  
Модифікатор `virtual` у базовому класі дозволяє методу бути зміненим у похідних класах[cite: 4]. Модифікатор `override` у похідному класі надає нову реалізацію цього методу[cite: 4]. Разом вони забезпечують динамічний поліморфізм, коли правильна версія методу викликається залежно від фактичного типу об'єкта під час виконання.

4. Коли варто використовувати модифікатор new для приховування члена базового класу, і які наслідки це має?  
Модифікатор `new` використовується, коли потрібно явно приховати успадкований член базового класу новим членом з тим самим ім'ям, не використовуючи поліморфізм[cite: 4]. Наслідок полягає в тому, що виклик методу залежить від типу посилання, а не від типу самого об'єкта.

## Структура ієрархії класів

### 1. Базовий клас `Building`
* Поля та властивості: `Address`, `YearBuilt`[cite: 4].
* Віртуальний метод: `GetInfo()`[cite: 4].
* Метод: `GetBuildingType()`.

### 2. Похідний клас `House`
* Поле: `NumFloors`[cite: 4].
* Перевизначений метод: `override void GetInfo()`[cite: 4].
* Прихований метод: `new string GetBuildingType()`.
* Унікальний метод: `OpenDoor()`[cite: 4].

### 3. Похідний клас `Skyscraper`
* Поле: `NumElevators`.
* Перевизначений метод: `override void GetInfo()`[cite: 4].
* Унікальний метод: `GoToRoof()`.
