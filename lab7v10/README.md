# Лабораторна робота №7

## Тема
Узагальнені типи (Generics). `IRepository` з `where`-обмеженнями та тестами.

## Мета
Навчитися створювати узагальнені інтерфейси та класи, застосовувати `where`-обмеження для типів-параметрів, а також розробляти юніт-тести для перевірки коректності узагальнених реалізацій.

## Варіант 10
* **Сутність:** `Book` (властивості: `Id`, `Title`, `Author`, `PublicationYear`).
* **Архітектура:**
  * `IEntity`: Базовий інтерфейс із властивістю `int Id { get; set; }`.
  * `IRepository<T> where T : IEntity`: Узагальнений інтерфейс репозиторію зі стандартним набором CRUD-операцій (`GetById`, `GetAll`, `Add`, `Update`, `Delete`).
  * `InMemoryRepository<T>`: Реалізація репозиторію для зберігання сутностей у пам'яті (`List<T>`) з валідацією наявності та унікальності ідентифікаторів.
  * `lab12v10.Tests`: Проєкт модульного тестування на базі **xUnit**, що перевіряє всі методи CRUD та обробку виняткових ситуацій (спроби читання, оновлення чи видалення неіснуючих елементів).
